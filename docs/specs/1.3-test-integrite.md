# Spécification — 1.3 Test d'intégrité d'archive

## Objectif

Commande `test_archive(path, password)` vérifiant 100 % des entrées d'une
archive ZIP, RAR ou 7z sans extraction, avec un rapport clair en français.

## Critères d'acceptation

1. ZIP : chaque entrée est décompressée jusqu'au bout vers un « sink » — la
   crate `zip` valide le CRC-32 en fin de lecture ; les entrées chiffrées
   exigent le mot de passe (sinon erreur typée `PasswordRequired`).
2. RAR : test natif `before_file.test()` de la crate `unrar` (ERAR test,
   sans extraction).
3. 7z : lecture complète de chaque entrée vers un « sink » — le lecteur
   sevenz-rust vérifie le CRC de chaque sous-flux.
4. Progression/annulation identiques aux autres opérations (événement
   `operation-progress`, jeton d'annulation), durée du test dans le
   résultat.
5. Bouton « Tester » dans la barre d'outils de l'archive ; le mot de passe
   saisi est utilisé.
6. Tests cargo : archive ZIP valide → ok ; ZIP corrompu (octet altéré dans
   les données) → échec ; 7z valide → ok.

## Hors périmètre

- Test d'archives TAR (Phase 3.1).
- Réparation d'archives (refusé par la roadmap, cf. ROADMAP.md).
