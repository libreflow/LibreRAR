# Spécification — 3.3 Aperçu avant extraction & 3.4 Sommes SHA-256

## 3.3 Aperçu

- Commande `preview_entry(path, entry_name, password)` : contenu d'une
  entrée lu en mémoire (cap 4 Mio), sans extraction sur disque.
- Textes usuels (txt, md, json, xml, csv, code, html, css…) servis en UTF-8
  (lossy) ; images (png, jpg, gif, webp, bmp, ico, svg) en base64.
- Support ZIP, RAR, 7z, TAR (volumes .001 réassemblés au besoin) ;
  mot de passe des entrées chiffrées requis.
- UI : bouton œil par ligne de fichier, modale (texte en `pre`, image en
  data URL), fermeture Échap/arrière-plan.

## 3.4 Sommes de contrôle

- Commande `checksum_archive(path)` : SHA-256 (hex) de l'archive
  (volumes réassemblés), avec taille et nom de fichier.
- Commande `export_checksum(path, dest)` : écrit `<hash>  <nom>`
  (format sha256sum) à l'emplacement choisi ; destination existante refusée.
- UI : bouton « SHA-256 » dans la barre d'outils, hash affiché avec
  actions « Copier » (presse-papiers) et « Exporter… » (dialogue).
- Dépendances auditées : `base64 0.22`, `sha2 0.10` (RustCrypto, actifs).
- Test : SHA-256 de "abc" vérifié sur valeur connue.
